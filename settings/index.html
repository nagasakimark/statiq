App and offline files

Statiq Office works in the browser without either step. Install adds a desktop window and file-open handlers. Saving editors stores them on this device so they keep working with no network. Both share the same cache — order does not matter.

Install the app

Add Statiq Office to your desktop or home screen. On ChromeOS, the installed app can open Word, Excel, PowerPoint, and PDF files from the Files app. Saves write back to disk when you opened the file from your device.
